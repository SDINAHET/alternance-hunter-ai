# Alternance Hunter AI

Application locale de prospection d'alternances Bac+5 EADL : recherche d'entreprises, d'offres et suivi des candidatures.

## Démarrage

Node.js 20+ requis.

```bash
npm start
```

Ouvrir http://localhost:4173.

Version initiale en cours de construction. Ne pas publier de CV personnel, d'identifiants API ni de données privées.
