# Roadmap — Alternance Hunter AI

## Disponible
- Recherche d'entreprises (API Recherche d'entreprises)
- Recherche d'offres France Travail (identifiants API nécessaires)
- Suivi local et sauvegarde JSON
- Recherche assistée de contacts RH/CTO via liens Google et LinkedIn
- Scoring local indicatif par mots-clés
- Brouillons de candidature spontanée personnalisables et copiables
- Export CSV du suivi
- Actualisation périodique toutes les 30 minutes lorsque l'application est ouverte

## À réaliser
- Tests d'intégration sur les API réelles et gestion des quotas
- Recherche et validation d'emails professionnels publics avec provenance
- Statuts et relances éditables, filtrage de l'alternance par type de contrat
- Analyse IA facultative (API OpenAI, coûts à l'usage)
- Extraction du CV en local, consentement et stockage chiffré si nécessaire
- Adaptation du CV par entreprise et export PDF
- Envoi de courriels après approbation explicite
- Interface React et base PostgreSQL si le volume le justifie

## Confidentialité
Ne pas committer de CV personnel, de clés API, d'emails privés ou de base de données de prospection. Les messages LinkedIn sont à envoyer manuellement.
